Explorer Ahmedabad

Explorer Ahmedabad is an Android city exploration application built with Kotlin and Jetpack Compose. The project focuses on modern Android UI development, adaptive layouts, navigation, and MVVM architecture.

The application presents information about Ahmedabad's notable places through a responsive and adaptive user interface designed to work across different screen sizes.

Features

Explore notable places in Ahmedabad
Adaptive UI for different screen sizes
Responsive layouts using Jetpack Compose
Navigation between different screens
Reusable Compose UI components
MVVM architecture
Material Design components
Support for different device configurations

Tech Stack

Kotlin
Jetpack Compose
Material 3
MVVM Architecture
Navigation Compose
Adaptive UI
Android SDK
Android Studio

Architecture

The project follows the MVVM (Model-View-ViewModel) architecture to maintain separation between UI and application logic.
